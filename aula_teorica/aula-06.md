# O que é JUnit 5

## Framework para testes unitários.

## Arquitetura
- Plataform - base pra inicianização de frameworks e tests na jvm, fornece mecanisco de test para desenvolver e executar framework de tests, intellij, maven etc 
- JupiterAPI - combinação do novo modelo de programação e extensão para implementar tests e extenções no JUnit 5 - nome da api que usamos para implementar, oferece anotações e asserts - podemos criar nossa propria versao (solidos conhecimentos) 
- Vintage - mecanismo de backward compatibility para execurar tests mais antigos, usado para testar Junit 3 e 4.
